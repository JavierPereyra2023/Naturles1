# AGENTS_STYLE.md — Guía visual para páginas educativas

## 1. Objetivo visual

Usar esta guía para generar páginas web educativas con una estética moderna, oscura, elegante y dinámica.

El diseño debe inspirarse en una landing page profesional, pero adaptada a contenidos escolares de Ciencias Naturales, Biología, Física, Química o Matemática.

La página debe sentirse como:

- una presentación interactiva;
- una web educativa moderna;
- un material para proyectar en clase;
- un recurso visual para estudiantes de secundaria.

---

## 2. Tecnologías permitidas

Usar:

- HTML
- CSS
- JavaScript
- TailwindCSS vía CDN
- Iconify vía CDN
- Google Fonts vía CDN

No usar backend ni frameworks complejos.
# Guía de estilo visual

Usar:
- HTML, CSS, JS;
- TailwindCSS por CDN;
- Iconify;
- Google Fonts;
- Inter para textos;
- Oswald para títulos;
- fondo oscuro;
- paleta verde/cian para Biología;
- tarjetas con hover;
- botones con brillo;
- navegación fija;
- animaciones fadeInUp;
- diseño responsive.
